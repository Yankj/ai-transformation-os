# 语言与术语规范 / Language policy

## 原则 / Principle

中文是 ATOS 的主要表达语言；英文不是逐句翻译目标，而是保证技术术语准确、方便
国际协作和未来公开传播的辅助语言。

Chinese is the primary language of ATOS. English preserves technical precision,
supports external collaboration, and enables future public distribution.

## 文档要求 / Document requirements

| 文档类型 | 中文要求 | 英文要求 |
| --- | --- | --- |
| README、贡献与安全政策 | 完整中文内容 | 标题/摘要与关键术语 |
| 知识卡与实验报告 | 完整中文解释 | 标题、关键词、必要术语 |
| 对外文章和产品材料 | 中文优先 | 发布前制作独立英文版本，不做机械混排 |
| 代码、API、变量、测试 | 使用英文 | 英文为唯一规范 |

## 术语基线 / Glossary

| 中文 | English | 说明 |
| --- | --- | --- |
| 智能体 | Agent | 具备目标、决策与行动能力的系统单元 |
| 智能体运行时 | Agent Runtime | 编排状态、模型、工具、生命周期和观测的执行层 |
| 工作流 | Workflow | 可定义、可控制的多步骤业务流程 |
| 工具 | Tool | 由 Agent 受控调用的外部能力 |
| 知识库 | Knowledge | 可检索、可治理的知识资产与能力 |
| 评估 | Evaluation / Evals | 对质量、安全、成本或任务结果的系统验证 |
| 可观测性 | Observability | Trace、日志、指标和诊断能力 |
| 架构决策记录 | Architecture Decision Record (ADR) | 可追溯的架构取舍 |

术语首次出现时建议采用“中文（English）”形式，后续按上下文选择一种表达。
