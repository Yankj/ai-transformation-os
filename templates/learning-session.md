# 学习会话交接 / Learning session handoff

> 默认在对话中使用，不自动创建为仓库文件；只有在"归档"后才转化为知识卡、实验或复盘。

```text
主题 / Topic:
来源 / Sources:
我自己的理解（最多 3 点）:
做了什么实践 / Evidence:
仍然不懂或不确定的点:
最值得输出的一点:
当前阶段 / Current phase: (1-6)
```

## 共同复盘 / Joint review

```text
今天被验证的结论：

实践证据：

内容种子：
明天唯一的学习问题：
是否归档：是 / 否
```
