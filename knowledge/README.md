# Knowledge base

Knowledge is a network of small, evidence-aware assets—not a chronological
diary. Create a topic folder only when it has a durable question.

## Current domains

- [`delivery-paradigm/`](delivery-paradigm/README.md): 需求复杂度变化时，交付应由谁完成、如何受控。
- [`ai-engineering/`](ai-engineering/README.md): Docs、Rules、Skills、Workflow 与 Agent 如何分层演进。
- [`agent-runtime/`](agent-runtime/README.md): MVP-01 core concepts and links.
- [`agent-evolution/`](agent-evolution/README.md): Capability maturity model from Prompt to Self-Learning.
- [`llm-fundamentals/`](llm-fundamentals/README.md): Transformer 架构、注意力机制、Decoder-Only 选型、采样策略、预训练与推理。

Use [the knowledge-card template](../templates/knowledge-card.md). When a card
changes implementation or prioritisation, link an experiment or ADR.
